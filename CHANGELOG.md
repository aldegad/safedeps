## Unreleased

- Closed every read a verdict rests on that ran where errexit is off. A jq, curl, npm or find that printed and then exited non-zero no longer reads as success in `check`, `re-check`, `revoke`, `audit`, `gates run` or the effect gate's provider requests. A curl that printed 200 and failed is a failed request in the CLI and in the core. An approval is written only once its entry, its record and its report are all made. A check stopped by anything else answers `check_did_not_finish` with exit 4 instead of the exit status of whatever stopped it. A ledger whose files could not be listed answers `ledger_unlisted` with exit 4 in `ledger`, `revoke` and `re-check`, where it used to read as empty.
- Narrowed the deny after a failed reading of a command to the two cases where a reading found an install or the command's text reads as an install. A command that only names a package manager inside another word (`pipefail`) or with a manager that installs nothing (`npm run`) is now allowed, with the failure still on stderr and in `advisory.log`. An install behind a wrapper, inside a quoted script or heredoc, split by line continuations or redirections, or spelled with quotes, escapes or a path is still denied as `UNDECIDED`. The allowed message now says "does not read as an install" where it said "names no package manager", and the advisory line of a deny names which of the two answers denied it.
- Changed the text test that decides a command after a failed reading, whose match of an install's structure kept being fooled. The test now reads the command as a set of words, in no order and with no structure. A view is the text after any sequence of eight rewrites: line continuations joined, the escapes of printf and `$'...'` expanded with an octal escape past 255 standing for its low byte, the escapes of `echo -e` and the `%b` of printf expanded, each whole `$'...'` expanded to its bytes with the text outside it left for the bare cut, quote characters dropped with backslashes kept, each `${name-word}` and `${name:-word}` replaced by its word, each expansion dropped, and a glob's group of zsh or of bash's extended globs written as the words it matches. A manager or install verb assembled across an intact `$'...'` escape boundary, where the shell makes an escape a byte inside and the ordinary char outside, now reads as the install it runs (`pip $'\x69'\nstall` is `pip install`, `\pi$'\x70'\3 install` is `pip3 install`); only a `$'...'` whose opening `$'` the outer quotes split stays out of reach, like a run-time name. A decoy `$'` in a double-quoted string or a comment cannot swallow a real opener, because a `$'...'` expands only where it closes inside one word. Each view is cut into words at blanks, quotes, `$`, backquotes, brackets, redirection and operator characters, `,`, `=` and glob characters, with and without its quotes and backslashes, and the words are folded to lower case. Brace expansions add the words they make, and a word with a glob character also stands for a name or verb it matches with at most one byte open. The words read as an install where they hold a package manager's name, as a word or as the end of a word's path, and one of that manager's install verbs as a word beside it, in any order. This denies more commands than before: any whose words name a manager and one of its verbs apart, such as a manager in a log line and a verb in a script beside it. A text with more than 1024 views (`UNSCANNED_VIEWS`), a sequence of more than 64 views (`UNSCANNED_DEPTH`), or brace expansions past 16 MB (`BRACE_BYTES`) reads as an install, because it was not all read.
- Replaced external `file` command with a supervised core child reading coherent image headers directly (ignoring scripts and text) across up to 20 sorted `.bin` targets and symlinks for ELF, Mach-O, and PE images. Candidates are strictly read without execution, offering no loadability or safety guarantee; inspection inability triggers fail-closed rollback. Core processes now run `npm`, `curl`, `gzip`, judgment, and native-inspection child, removing `file`.
- Added a second resolution with the package pinned to its own version in probe overrides for probe failures on npm before 11.6.0 caused by cyclic optional peer dependencies. The closure is judged only if a second run without the pin confirms that npm leaves the lockfile unchanged, reporting `npm_closure_resolution_failed` otherwise.
